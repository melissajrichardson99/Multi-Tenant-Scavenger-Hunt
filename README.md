# Cobbs-Scavenger-Hunt
A scavenger hunt application built for Cobb's Adventure Park. Involves scanning QR codes of characters around the park and tracking progress to find all the characters.

### How to Run Locally
1. In the root project folder, navigate to the backend folder using: cd backend
2. Run the following command: python -m uvicorn app.main:app --reload --port 8000
3. In a seperate terminal, navigate to the frontend folder from the root project folder using: cd frontend
4. Run: npm install
5. Run: npm run dev

Note: Ensure required packages are installed using: pip install -r requirements.txt
